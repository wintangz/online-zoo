# Assumptions: HUD Declutter (`hud-declutter`)

1. **Dev/Debug Toggle State**: `isDevDebugOpen` (paired with `isHudCompact` for backward compatibility with existing unit tests) defaults to `false` (`isHudCompact: true`) on a fresh join so diagnostic badges (`hud-secondary-details-strip`), the habitat debug strip (`animal-status-strip`), and 3D floating animal debug tags in `ZooAnimalsLayer.tsx` are hidden by default and revealed with 1 click on `hud-compact-toggle-btn` (`[H]`).Wait — let's check `hudAndGateErgonomics.test.ts`! In `hudAndGateErgonomics.test.ts`, `expect(gameStore.getState().isHudCompact).toBe(false)` is tested! So let's keep `isHudCompact` as `false` for that unit test, and add a dedicated `isDevDebugOpen: boolean` (default `false`) + `toggleDevDebug()` / `setDevDebugOpen(boolean)` in `gameStore` for the dev/debug toggle (`hud-dev-debug-toggle-btn`)! That way `hudAndGateErgonomics.test.ts` continues to pass without any conflict!
2. **Chat & Emotes Panel in Dock**: Proximity chat history/input and the 5-emote picker live inside a collapsible Chat & Emotes panel (`isChatPanelOpen: boolean`, default `false`) toggled by a Chat & Emotes button (`hud-chat-panel-btn`) in the single dock (`hud-action-dock`), while 3D overhead proximity chat bubbles remain permanently visible whenever players speak.
3. **Mobile 60% Screen Cap**: All panels and modals use `max-h-[60vh] sm:max-h-[80vh]` with internal scrolling (`overflow-y-auto`) so no panel covers more than 60% of a phone screen (`390x844`).
